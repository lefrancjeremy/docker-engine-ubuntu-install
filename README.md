# docker-engine-ubuntu-install

Installs Docker Engine on Ubuntu via the official repository, with GPG key fingerprint verification.

## Usage

```bash
chmod +x install_docker_engine.sh
sudo ./install_docker_engine.sh --dry-run
sudo ./install_docker_engine.sh
```

See the comments at the top of `install_docker_engine.sh` for full details
(requirements, options, security guarantees, known limitations).
